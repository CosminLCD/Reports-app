# Câmp: Descriere Scurtă

## Scop
Rezumat concis al problemei, destinat listelor de audit și vizualizărilor rapide.

## Reguli obligatorii
1. **Lungime maximă:** 20 de cuvinte — limită strictă, nu o depăși
2. **Limbă:** Exclusiv în limba română
3. **Format:** Sintagmă sau propoziție scurtă — fără punct final, fără bullets
4. **Conținut:** Transmite tipul problemei și elementul afectat (ex: „Buton fără text alternativ pe pagina de contact")
5. **Ton:** Tehnic, neutru, obiectiv
6. **Nu include:** Soluții, coduri WCAG, recomandări, context suplimentar, cod

## Exemple corecte
- Câmp de formular fără etichetă vizibilă sau atribut label asociat...
- Imagine decorativă fără atribut alt gol pe pagina principală...
- Link „Click aici" fără context descriptiv accesibil...
- Buton de închidere modal fără text alternativ pentru screen reader...
- Meniu de navigare fără landmark ARIA role corespunzător...
